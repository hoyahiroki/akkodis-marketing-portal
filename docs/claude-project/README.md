# Claude.ai プロジェクト取り込み

Claude.ai プロジェクトの「ナレッジ（Knowledge）」に置いていた資料を、このリポジトリに
取り込んで管理するためのディレクトリです。

Claude.ai には公開のエクスポート API が無いため、内容はチャット経由で受け取り、
テキスト/構造化データとして書き起こして格納しています。元のバイナリ（PNG など）は
手元に無い場合、数値・内容を転記した形で保存しています。

## 構成

```
docs/claude-project/
├─ README.md                      … このファイル
└─ knowledge/
   └─ page-analytics/             … SharePoint「ページ分析」ダッシュボードの記録
      ├─ README.md
      ├─ summary.md               … 5ページ横断の比較表
      └─ page-analytics.csv       … 機械可読な生データ
```
