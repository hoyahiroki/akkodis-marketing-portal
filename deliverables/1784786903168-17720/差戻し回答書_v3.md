## 【全体】クイックリンクの4カラム
- ご指摘どおり。**クイックリンク web partは4個以上の横並び表示が可能**（Grid/Tiles/Button等のレイアウトで画面幅に応じて自動フィット。V8）。**3列上限は「ページのセクションの列レイアウト」由来**で、そこに強調表示されたコンテンツ/リスト等を並べる場合の話でした。→ **クイックリンク（4カテゴリカード・クライアント・Social Media）を4列に戻しました**。
- 補足（正直な注記）: 公式ドキュメントは「必ず4列」といった固定列数は明記しておらず、レイアウトのレスポンシブ挙動として4〜6個程度が横並びになります。厳密に「4列固定」が要件なら**プレビュー環境での実測**をおすすめします。

## 【トップ】T-4 縦積み
- 「イイネ」ありがとうございます。3カラムだと1カラム幅が狭くなる件、ご提案どおり**縦積み（上から下へ全幅の3ステップ）に変更**しました（①AI-1自己チェック→②手順ガイド→③業務依頼フォーム）。各ステップが全幅で内容を余裕を持って表示できます。

## 【ブランドライブラリ】
- **サブブロックごとの背景色はつけられるか** → **背景色は「セクション単位」でのみ設定可能**（V9）。1つのテキストパーツ内のサブブロックごとに別背景色を付ける機能はありません。→ 色分けしたい各サブブロック（「ブランドレビュー依頼の前に」「注意事項（社外秘）」等）を**それぞれ独立したセクションにして、セクション背景色**を付ける形にWFを直しました。（テキストパーツ内テーブルは5種の定型スタイルのみで任意セル色は不可）
- **画像素材のテキストパーツとクイックリンクの使い分け** → ご指摘どおり過剰でした。**テキストパーツだけ**に簡素化しました（テキスト内に4見出し＋各リンクを箇条書き）。
- **各種テンプレートの強調表示されたコンテンツの使い方（5見出しを一緒くたか／見出しごとか）** → **見出しごと**が正解です。強調表示されたコンテンツ web partには**グループ表示機能がありません**（V10）。5カテゴリ（PowerPoint/Word/メール署名/Forms/バーチャル背景）を分けて見せるには、**カテゴリごとに5つの強調表示されたコンテンツ web partを置き、各にコンテンツタイプ／メタデータのフィルタを設定**します（各web partの上にカテゴリ見出しを添える）。WFを5つに分けて描きました。

## 【クライアント向け】
- **クイックリンクを4列に戻す** → 戻しました（AKKODiS企業向けWebページのセミナー/活用事例/Insights/サービス＝4列）。
- **リストパーツ＝SharePoint上に新規リストを作成、で合っているか** → **はい、その理解で正しいです**。外部サイトへのリンク集を**新規のカスタムリスト（ハイパーリンク列＋カテゴリ/言語/更新日列）**として作成し、ビューで絞り込みます。※これは「変更不可の既存ガイドラインライブラリ」とは別で、**リンク集用の新規リストを1つ作る**という意味です（新規作成が難しければ、テキストパーツにリンクを並べる代替も可能・その場合は列絞り込みは付きません）。

## 【全ページ横断】AI-2について
- **SharePoint agent方式は結局生成AIを使うのか** → **はい、生成AI（LLM）を使います**（公式明記: "Copilot in SharePoint uses AI services to generate responses."）。サイト内の資料を根拠に回答します。
- **クライアントページのHPに飛ぶリンクを探し当てられるか** → **正直に申し上げると、一次情報に断定記載がなく"要実機確認"です**。分かっているのは、エージェントは「利用者が権限を持つサイト・ページ・ドキュメント」を根拠に回答し、**該当リンクが載っているページを出典として案内できる**こと。ページ本文に書かれたリンク（URL文字列/アンカーテキスト）もテキストとして索引され得るため、**質問に応じて回答文中で言及・提示できる可能性は高い**ですが、外部URL自体を直接返すか/ページを出典案内する形かは公式に明記がありません。→ 実装フェーズで**AKKODiSの実サイトで試す（実機検証）**ことをタスク化します。

## 【KPI】空振り率の刷新前後比較
- **鋭いご指摘ですが、比較は可能です**。現行ポータルの標準検索（「このサイトを検索」）でも、**Search usage reports（ゼロ件検索＝No Results Queries を含む）は標準で記録・閲覧できます**（V13。サイト設定→サイトコレクション管理→Microsoft Search→Insights）。→ **刷新前のベースラインは既存データがそのまま使えます**（過去31日/12か月、Excel出力可）。刷新後との「ゼロ件検索率・人気検索語の推移」を比較できます。
- 注意点: ①閲覧には**サイトコレクション管理者権限**が必要 ②保持は**最大12か月**（それ以前はダウンロード保存が必要） ③刷新でサイト構成・URL体系が変わるとクエリ母集団の意味が変化し単純比較しにくくなる場合がある——この3点は付言します。
