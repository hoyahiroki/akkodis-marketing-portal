# materials — 現状サイトの調査資料置き場

マーケティングポータル リニューアルの入力資料をここに格納します。

## 置き方

| ディレクトリ | 入れるもの | 対象ファイル |
|---|---|---|
| `materials/screenshots/` | ページのスクリーンショット（PC/SP） | top_pc.png / top_sp.png / brand_pc.png / brand_sp.png / client_pc.png / client_sp.png / candidate_pc.png / candidate_sp.png / partner_pc.png / partner_sp.png |
| `materials/analytics/` | 各ページのアナリティクスのスクリーンショット | top_ana.png / brand_ana.png / client_ana.png / candidate_ana.png / partner_ana.png |

- ファイル名は上記のままでOK（変わっていても拾います）
- GitHubのWeb画面から: 各ディレクトリを開く → 「Add file」→「Upload files」→ ドラッグ＆ドロップ → Commit
- 15枚すべて揃わなくても、あるものから分析を始められます

アップロードが終わったら、管制室かチャットで一言ください（自動検知も仕込んでありますが、確実なのは一言です）。
